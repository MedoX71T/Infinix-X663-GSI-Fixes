# Problem Wall — risks and reports

Use [GitHub Issues](https://github.com/MedoX71T/Infinix-X663-GSI-Fixes/issues) for firmware-specific failures, GSI compatibility reports, patch problems, and unexpected behavior.

## Limits

- Firmware-specific images may not work on another stock build.
- Bootloader unlocking erases data. Keep backups and matching stock recovery images.
- LK warning removal is optional and does not provide the networking fix.
- VoLTE, VoWiFi, hotspot, and SELinux behavior need firmware- and GSI-specific evidence.
- A hash identifies a file; it does not establish a trusted signature or device compatibility.

No universal permissive-SELinux requirement, precise hotspot failure duration, or unverified memory-leak cause is asserted.

## Useful reports

Include the full stock-firmware string, GSI repository and exact release, changed images/partitions, symptoms, and relevant logs. Remove private information from logs before publishing.
