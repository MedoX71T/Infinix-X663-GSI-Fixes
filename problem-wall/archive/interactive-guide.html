Welcome!

What This Guide Does

This interactive guide will help you install custom Android (GSI) on your Infinix Note 11 (X663) with working WiFi and mobile data.

You'll learn to:
  • Install custom Android versions (LineageOS, Pixel Experience, etc.)
  • Fix WiFi and mobile data on Android 14+
  • Remove bootloader warning screens
⚠️ Before You Start This process will erase all your phone data. Backup everything important first!

Estimated Time

30-45 minutes (varies by internet speed)

1

Check Your Firmware

Find Your Build Number

  1. Open Settings on your phone
  2. Scroll down and tap "My Phone" (or "About Phone")
  3. Find "Build Number"
  4. It looks like: X663-H6915...
  5. Write it down somewhere safe
✓ Why This Matters You need the exact firmware version to download the correct files. Using wrong files can brick your phone.

Mark when complete:

2

Download Stock ROM

Get Your Phone's Original Software

  1. Google: "Infinix X663 Stock ROM [your build number]"
  2. Download the ZIP file (2-4 GB)
  3. Extract using WinRAR or 7-Zip
  4. Find these files inside:
    • boot.img
    • lk.img
    • vbmeta.img
  5. Copy boot.img to your phone storage
  6. Keep lk.img and vbmeta.img on PC
⚠️ Important: Firmware Version Matters These files are specific to YOUR firmware version. Don't use someone else's patched files unless firmware matches exactly!

Mark when complete:

3

Patch Boot Image

Apply Network Fix (On Phone)

  1. Download BPF Patcher APK:
    https://xdaforums.com/attachments/mtk-bpf-patcher-release-apk.6238876/
  2. Install the APK on your phone
  3. Open BPF Patcher app
  4. Tap "Select Input File"
  5. Choose the boot.img you copied
  6. Tap "Patch" and wait
  7. Copy patched_boot_bpf.img back to PC
✓ What This Does This adds BPF (Berkeley Packet Filter) support to your kernel, which Android 14+ needs for network functionality.

Mark when complete:

4

Setup PC Tools

Prepare Your Computer

  1. Download Platform Tools:
    https://developer.android.com/tools/releases/platform-tools
  2. Extract to folder (e.g., C:\platform-tools\)
  3. Copy these files into that folder:
    • patched_boot_bpf.img (from Step 3)
    • vbmeta.img (from Step 2)

Patch LK Image (Warning Fix)

  1. Download lkpatcher:
    https://github.com/R0rt1z2/lkpatcher
  2. Extract and copy your lk.img there
  3. Install Python 3 if needed
  4. Open terminal in lkpatcher folder
  5. Run: python3 -m lkpatcher lk.img -o patched_lk.img
  6. Copy patched_lk.img to platform-tools folder

Mark when complete:

5

Unlock Bootloader

⚠️ DATA LOSS WARNING This step will erase ALL phone data. Make sure you have backups!

Enable Developer Options

  1. Settings → About Phone
  2. Tap "Build Number" 7 times
  3. Go back → Developer Options
  4. Enable "OEM Unlocking"
  5. Enable "USB Debugging"

Unlock Process

  1. Connect phone to PC
  2. Open PowerShell in platform-tools folder (Shift + Right-click)
  3. Type commands:
adb devices
(Phone: Tap "Allow")

adb reboot bootloader

fastboot flashing unlock
(Phone: Select "Unlock" with volume buttons)

Mark when complete:

6

Flash Custom Android

Choose Your GSI

  • Pixel Experience - Recommended for beginners
  • LineageOS - Privacy-focused
  • DerpFest - Feature-packed

Flash Commands

adb reboot bootloader

fastboot reboot fastboot

fastboot --disable-verification flash vbmeta vbmeta.img

fastboot --disable-verity --disable-verification flash vbmeta_system vbmeta.img

fastboot erase system

fastboot flash system [drag GSI file here]

On phone: Select "Wipe all data" → "Reboot to system"

✓ Almost There! Your phone now runs custom Android, but WiFi/data won't work until next step.

Mark when complete:

7

Fix Network

Apply Network Patches

adb reboot bootloader

fastboot reboot fastboot

fastboot flash boot patched_boot_bpf.img

fastboot reboot bootloader

fastboot flash lk lk-patched.img

fastboot reboot
✓ All Done! WiFi and mobile data should now work perfectly!
