# Gathering Table — community guidance

Share reproducible results, firmware-specific patches, and GSI compatibility findings.

## Where to share

- [GitHub Issues](https://github.com/MedoX71T/Infinix-X663-GSI-Fixes/issues): the workshop’s public record.
- [Maintainer Telegram](https://t.me/MedoX71T): existing maintainer contact.
- [Doze-off GSI group](https://t.me/dozeoff_treble): upstream GSI community, not a dedicated Forge forum.

GitHub Discussions is not promoted while disabled.

## Report contents

1. Original stock-firmware identifier.
2. GSI project, release link, and exact build.
3. Images and partitions changed.
4. Symptoms and reproduction steps.
5. Results, including failures.
6. Relevant logs with private data removed.

Cite upstream sources. Keep known results separate from speculation. Sharing a patch does not establish compatibility for another firmware build.
