## Usage

Add to every release, README update, or significant patch contribution.

**Variables:**
- `[VERSION]` - Semantic version (3.0, 3.1, etc.)
- `[DATE]` - YYYY-MM-DD format
- `[NAMES]` - @username1, @username2
- `[BASE FIRMWARE]` - X663-H6915... (firmware this patch targets)

**Example:**
```
╔═══════════════════════════════╗
║  FORGE X663 - MAKER'S MARK   ║
║  Version: 3.1                 ║
║  Forged: 2026-11-15          ║
║  Contributors: @MedoX71T      ║
║  Device: Infinix Note 11     ║
║  Base Firmware: X663-H6920    ║
║  Android: 14 · 15 · 16       ║
╚═══════════════════════════════╝
```

This mark signifies:
- Tested work, not experimental
- Contributors credited
- Firmware compatibility clear
- Part of Forge workshop lineage
